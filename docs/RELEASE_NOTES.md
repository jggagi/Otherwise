Windows x64 离线发行候选版，2026-10-09。

解压整个目录，双击 Otherwise.exe。Otherwise.pck 必须与程序放在一起。
不需要安装 Godot、不需要账号或网络。游戏默认窗口为 1280×720。

WASD／方向键：移动。也可以点击空闲地面自动行走。
E：附近物件交互／继续对白。空格或 Enter 也可推进对白。
数字 1–9 或鼠标：选择选项。ESC：暂停、声音、字号和重开。
标题页可继续上次进度；现实关键节点自动保存，模拟中不保存。
存档和声音／字号配置位于 %APPDATA%\Godot\app_userdata\Otherwise。
字号可放大到 135%，静音也能理解全部剧情；较长面板可滚动。

一个雨夜，三种开场，一次可选 ELSE 重构，两种最后回应。
林夏明早离开城市。ELSE 只能重构另一种可能，现实的决定仍由你承担。
不重构也可完成故事；若使用 ELSE，读到线索后可回到现实检查书架。
