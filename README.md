# Otherwise

> A contemporary narrative game about the lives that might have happened otherwise.

**Engine:** Godot 4  
**Setting:** 2026, present-day Chinese city  
**Genre:** Narrative game / urban magical realism / counterfactual mystery  
**In-world software:** **ELSE**

## Core premise

A normal rainy night. The protagonist receives a message:

> 林夏：我在你楼下。

The player makes an ordinary choice. Later, a personal side-project on the protagonist's computer — **ELSE** — offers to reconstruct what might have happened if a different choice had been made.

At first, these are clearly framed as AI-generated counterfactual simulations built from ordinary personal data: messages, photos, calendar history, locations, and other traces of daily life.

Then the simulations begin to contain details that the model should not know.

The game is not about finding the “best ending.” It is about understanding how small choices reshape relationships, memory, and the version of oneself that becomes real.

## First playable goal

Build a **20–30 minute vertical slice**:

- one contemporary apartment
- one rainy night
- one NPC: 林夏
- one triggering message
- three small branches
- a few environmental differences between branches
- one early **Anchor**: knowledge the player can carry between otherwise separate timelines

Do **not** build the full game before this slice feels good.
